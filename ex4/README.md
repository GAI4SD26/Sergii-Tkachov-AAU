# Snake on the Grid

A single-player Snake game with an isometric-style board.

## Play

Open `index.html` directly in a modern desktop browser with WebGL enabled. No installation, build, server, or network connection is needed.

Select **Start playing** and use the arrow keys to steer along the board. The on-screen legend shows the projected direction for each key. Eat the fruit to grow and earn points; hitting the edge or your body ends the round. Select **Play again** to restart.

## Verify

Open `tests/game-tests.html` directly in the browser to run the rule and UI tests. For the full browser and offline smoke-test procedure, see [quickstart.md](specs/001-isometric-snake/quickstart.md).
